# بورتفوليو المصور والمخرج السينمائي محمد علي (Mohamed Ali Portfolio & CMS)

موقع ويب احترافي وتفاعلي بتصميم داكن فاخر (Cinematic Dark Mode) مخصص لعرض أعمال التصوير الفوتوغرافي والفيديو السينمائي للمصور والمخرج **محمد علي (Mohamed Ali)**، مع دعم رفع الأعمال عبر الروابط أو رفع الملفات مباشرة من جهازك، ولوحة تحكم متكاملة، وقائمة تواصل وحجز مباشرة.

---

## 🌟 الميزات الرئيسية

1. **هوية بصرية سينمائية متكاملة لمحمد علي (Mohamed Ali)**:
   - شعار وهوية احترافية باللونين الذهبي والأسود الملكي (Cinematic Obsidian & Gold).
   - عرض خبرات وسنوات العمل، الإحصائيات، الخدمات، وقائمة المعدات السينمائية (Sony FX6, FX3, DJI Ronin, Aputure).

2. **دعم مرن لرفع وإضافة الأعمال (روابط + رفع ملفات مباشرة من الجهاز)**:
   - **عبر الروابط**: دعم كامل لروابط YouTube و Vimeo والروابط المباشرة لملفات MP4 والصور الخارجية.
   - **رفع ملفات مباشرة إلى الموقع**: إمكانية اختيار ملفات الصور والفيديوهات مباشرة من جهاز الكمبيوتر أو الموبايل ورفعها تلقائياً إلى مجلد `uploads/` مع توليد روابط محلية دائمة وشريط تقدم للرفع.
   - مشغل فيديو مدمج يشغل الفيديوهات المرفوعة مباشرة من السيرفر كفيديوهات HTML5 عالية الجودة، بالإضافة إلى مشغلات YouTube و Vimeo.
   - عارض صور سينمائي (Lightbox) لمشاهدة الصور بالحجم الكامل، التنقل بينها، واستعراض تفاصيل الكاميرا والعدسة وتاريخ العمل.

3. **قائمة تواصل تفاعلية وسريعة (Contact & Connect Hub)**:
   - بطاقات تواصل سريعة:
     - 💬 **محادثة واتساب مباشرة**: لبدء محادثة فورية لتفاصيل الحجز والأسعار.
     - 📞 **اتصال هاتفي مباشر**: للمحادثات العاجلة والمشاريع الفورية.
     - ✉️ **بريد إلكتروني رسمي**: لمقترحات المشاريع والعقود الرسمية.
     - 🌐 **شبكات التواصل**: إنستغرام، يوتيوب، فيميو، وبيهانس.
   - **زر عائم ذكي (Floating WhatsApp Widget)**: متاح في زاوية الشاشة طوال التصفح للتواصل الفوري.
   - **نموذج حجز جلسات ذكي**: يُنشئ رسالة واتساب منسقة ومفصلة ببيانات العميل ونوع الخدمة والموعد بضغطة زر.

4. **لوحة تحكم إدارية ومودال إضافة سريع (Admin Dashboard & Quick Add)**:
   - زر إضافة سريع في الصفحة الرئيسية لنشر أي صورة أو فيديو فوراً بدون مغادرة المعرض.
   - لوحة تحكم كاملة في صفحة `admin.html` لإضافة وتعديل وحذف أي عمل.
   - تعديل بيانات الملف الشخصي (الاسم، النبذة، روابط التواصل، رقم الهاتف والواتساب).
   - حفظ تلقائي للبيانات على السيرفر في ملف `data.json` مع ميزة تصدير واستيراد النسخ الاحتياطية (JSON Backup).

## 🚀 كيفية تشغيل الموقع

### الطريقة الأولى: التشغيل عبر سيرفر بايثون (مُوصى بها للاستفادة من ميزة رفع الملفات والحفظ التلقائي)
افتح موجه الأوامر (Terminal أو PowerShell) داخل مجلد المشروع ونفذ:
```bash
python server.py
```
- سيتم تشغيل السيرفر تلقائياً وفتح الموقع في متصفحك على: `http://localhost:8080`
- لوحة التحكم ستكون متاحة على: `http://localhost:8080/admin.html`
- جميع الملفات المرفوعة ستُحفظ تلقائياً داخل مجلد: `uploads/`
- جميع البيانات تُحفظ وتُحدث تلقائياً في ملف: `data.json`

### الطريقة الثانية: التشغيل المباشر في المتصفح (بدون أي برامج)
- افتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح (Chrome, Edge, Safari, Firefox).
- للوصول للوحة التحكم: افتح ملف `admin.html`.

## 📁 هيكل الملفات
- `index.html`: الصفحة الرئيسية للبورتفوليو وقائمة التواصل ومعرض الأعمال.
- `admin.html`: لوحة التحكم الشاملة لإدارة الأعمال والبيانات.
- `server.py`: سيرفر Python متكامل يدعم واجهة برمجة التطبيقات (API) لرفع الصور والفيديوهات وحفظ البيانات.
- `data.json`: ملف تخزين البيانات الدائم على القرص.
- `uploads/`: مجلد حفظ ملفات الصور والفيديوهات المرفوعة مباشرة من الجهاز.
- `css/style.css`: ملف التنسيقات والتأثيرات السينمائية وتدرجات الألوان.
- `js/db.js`: محرك التخزين والبيانات ورفع الملفات ومزامنة السيرفر.
- `js/app.js`: كود الواجهة الرئيسية والتصفية ومشغل الفيديو ونموذج التواصل.
- `js/admin.js`: كود لوحة الإدارة وإضافة وتعديل الأعمال وتحديث الملف الشخصي.

## 🌐 نشر الموقع على الإنترنت
يمكنك رفع مجلد المشروع إلى أي استضافة تدعم المواقع أو السيرفرات:
- **Netlify / Vercel / GitHub Pages**: لنشر الواجهة مجاناً.
- **Render / Railway / VPS**: لتشغيل سيرفر البايثون ورفع الملفات وحفظها سحابياً.
